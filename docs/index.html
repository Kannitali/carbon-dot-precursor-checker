这个判断是怎么来的？

工具向 OpenAlex 学术数据库实时检索“标题同时包含 carbon dots 类词与原料名”的论文；若 OpenAlex 不可用，自动切换到完全免费的 Crossref（无需注册、无每日配额）。若两者均未找到有效线索，再用 X-MOL 期刊文献库兜底检索（入口：x-mol.com/paper/chem）。再检查标题与摘要中的合成线索（如 from / derived / based on / carbonization of）和检测线索（如 detection of / probe for）。标题含合成线索的文献被判为“已见报道”；仅出现“检测某原料”的文献不计入原料证据。所有条目都给出真实 DOI，点击即可核对原文。

数据来自 OpenAlex 开放学术索引、Crossref DOI 注册库，兜底来自 X-MOL 期刊文献库；文献条目与 DOI 均来自数据库返回，未经人工逐篇精读。

“未检索到”不等于从未有人使用：建议换同义词、别名、化学式或掺杂形式再查，并以系统综述为准。
